Toggle Inputs (A, B, Cin):

Input A
Input B
Carry In (Cin)
SUM: 0
CARRY OUT (Cout): 1
Sum = A ⊕ B ⊕ Cin
Cout = (A · B) + (Cin · (A ⊕ B))
full_adder.v (Verilog HDL) RTL 
module full_adder (
    input  wire a, b, cin,
    output wire sum, cout
);
    assign sum  = a ^ b ^ cin;
    assign cout = (a & b) | (cin & (a ^ b));
endmodule
Simulated State: A=1, B=0, Cin=1 → Sum=0, Cout=1

Toggle Inputs (D0, D1, Select):

Input D0
Input D1
Select (SEL)
Output (Y): 1
Active Channel: D1 → Y
mux2to1.v (Verilog HDL) RTL 
module mux2to1 (
    input  wire d0, d1, sel,
    output wire y
);
    assign y = sel ? d1 : d0;
endmodule
SEL=1 routes D1 to Output Y.
